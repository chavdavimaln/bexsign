# 08 — Public Signing & Signature Creation Guide

## Public Signing Workflow (`/sign/:token`)
- Secure token verification with no login required for external signers.
- **Signature Creation Modal**:
  - **Type**: Type full name with styled cursive font options.
  - **Draw**: Interactive canvas drawing pad.
  - **Upload**: Upload signature image file.
- **Validation**: Enforces completion of all mandatory assigned fields prior to submitting.
- **Completion**: Generates audit certificate and dispatches confirmation notifications.
