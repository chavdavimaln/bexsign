# 04 — Dashboard Module

## Key Features
- **Welcome Bar**: Personalized greeting & quick status counters (Total Docs, In Progress, Completed, Pending).
- **Core 4 Quick Actions**:
  - **Send for Signature**: Upload → Recipients → Drag Fields → Send
  - **Sign Yourself**: Upload → Drag Fields → Sign → Download
  - **Use Template**: Select Template → Assign Recipients → Send
  - **Create Document**: Open creation modal with Desktop/Cloud options
- **Recent Documents**: Real-time table showing status tags, recipients, and creation dates.
