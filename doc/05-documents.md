# 05 — Documents & Document Editor Guide

## Document Lifecycle
`draft` → `scheduled` / `in_progress` → `completed` | `declined` | `expired` | `recalled` | `trashed`

## Document Editor Features
- PDF viewer canvas with interactive drop zones.
- **Standard Fields**: Signature, Initial, Name, Email, Date, Date Signed, Text, Number, Checkbox, Radio, Dropdown, Company, Job Title, Address, Phone.
- **Custom Fields**: Custom Text, Custom Number, Custom Date, Custom Checkbox, Custom Dropdown.
- **Field Configuration Popup**: Assigee selection, label, description, required toggle, and validation rules.
